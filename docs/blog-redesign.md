## 案例与取舍

- [Paco Coursey](https://paco.me/)：介绍、作品与写作之间层级清楚；借鉴内容优先与克制的界面。
- [Rauno · Craft](https://rauno.me/craft)：研究 Toolbar Morph、Theme Motion 等交互案例；将动效用于状态与操作反馈。
- [Brian Lovin · Writing](https://brianlovin.com/writing)：年份索引便于扫描；借鉴文章标题、日期与归档之间的关系。

不照搬案例版式。这个站点的读者主要寻找技术问题的解法，因此采用「开发者的个人工作台」：一张可打开的真实最新笔记作为首页视觉重点，其余内容保持平静、清楚。

## 视觉系统

- 冷白背景 `#F7F9FC`、白色表面 `#FFFFFF`、墨蓝正文 `#172338`、蓝色强调 `#416BE8`、灰蓝辅助文字 `#64738B`、边框 `#DFE6F0`。
- 暗色采用深墨蓝背景、浅蓝文字；同一套语义变量覆盖组件。
- 展示与正文：现有 Satoshi 配合 PingFang SC / Microsoft YaHei；技术标注与日期：本地 JetBrains Mono；少量生活文字用系统宋体，避免额外中文字体下载。
- 宽屏约 1120px 内容区；首页介绍 / 最新笔记双栏，文章列表 / 个人侧栏双栏；手机按阅读顺序单栏。
- 标志性元素：带索引页签的叠层最新笔记，悬停展开与抬升，链接目标来自文章数据。
- 动效：短距离入场、叠层笔记展开、文章悬停与箭头位移、阅读进度；尊重 reduced-motion，不劫持滚动。实测浏览器对原生跨文档 View Transition 有兼容性错误，因此保留普通页面导航与 CSS 内容入场。

## 验证记录

已完成的验证：

- `bun run build`：类型检查 0 errors / 0 warnings，保留原项目 about/projects 页面中 6 个未使用导入提示；生成 105 个 Pagefind 索引页面及站点地图。
- 修改的 Astro 文件通过 ESLint；`git diff --check` 通过。
- 本次改写的组件、布局与样式通过 Prettier 格式检查。
- 首页在 320、390、768、1440px 实测文档宽度等于视口宽度；文章在 390、1440px 无页面横向溢出。
- 浅色 / 暗色切换及导航后的主题保留；移动导航展开、Escape 关闭与焦点返回。
- 新目录随阅读位置高亮；桌面锚点定位在顶部 120px，手机目录跳转后关闭并将焦点交给对应标题；阅读进度随滚动更新。
- 代码复制按钮显示成功反馈；⌘K 进入搜索；生产预览搜索 Codex 返回真实文章。
- 生产预览分页从第 1 页进入第 2 页；首页、文章列表 / 第二页 / 详情、标签 / 标签详情、归档、关于、项目、朋友、搜索、RSS、robots.txt、站点地图共 14 个入口均返回 HTTP 200。
- 最终首页与列表浏览无新增控制台错误；手机菜单关闭后 Tab 会进入正文，不会落入隐藏导航。
- 修复测试中发现的长摘要撑宽手机网格、悬停背景覆盖文字，以及 scroll-padding / scroll-margin 叠加造成的目录高亮偏差。

边界与限制：

- 本地 Twikoo 组件能加载，但服务端请求受 localhost 跨域策略限制；未发送评论，线上评论数据读写尚未验证。

- reduced-motion 的 CSS、目录原生锚点和回顶代码已检查；未修改操作系统设置来模拟该偏好。未进行真实手机硬件、全浏览器兼容性或 Lighthouse 分数测试。
- 沿用 Astro 6.3.0、现有字体与工具链，无新增依赖；文章内容、永久链接及评论配置保持原样。

本地查看：`bun run dev`；生产预览：`bun run build` 后运行 `bun run preview`。这次未部署或推送远端。
